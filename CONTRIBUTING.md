# Contributing to Roots & Rivers

Thank you for helping. You don't need to code to contribute.

## Ways to help

- **Report an error:** use the "Report a mistake" issue form. Include a source if you can.
- **Request a sensitivity review:** if a passage feels one-sided or unfair to a community, faith, country or language, use the "Request a sensitivity review" form.
- **Share how you used it:** teachers, club leaders and families, please use the "I used this book" form.
- **Share a story:** readers can submit a short story from an Ask Your Elders interview, with consent, using the "Share a story" form.
- **Review a chapter:** scholars and teachers of South Asia can volunteer with the expert review form.

## Ground rules

- Every fact needs a source you can link to. We never add statistics, quotes or stories we can't verify.
- Describe every community the way its own members would recognize. No ranking of faiths, countries or languages.
- Disputed territory and contested history are presented as disputed.

## Running the site locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Then open http://127.0.0.1:8000/south-asian-culture-textbook/.

Project rules for writers and editors are in `CLAUDE.md`. The design contract is in `Materials/textbook-design-principles.md`.
