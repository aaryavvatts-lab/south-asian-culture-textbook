# Learning Graph

A learning graph is a map of every idea in this book and which ideas you need first. Each of the 368 concepts is a node. An arrow from one concept to another means "learn this one first". For example, **Diwali** points to **Lunisolar Calendar**, because you need the calendar to understand why Diwali moves each year.

The graph keeps the book honest: no chapter uses an idea before the book has taught it.
